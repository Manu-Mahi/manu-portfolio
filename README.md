# Manu | Personal Portfolio

Welcome to my personal portfolio! A space showcasing my software engineering projects, technical experiences, and creative interests through interactive design and thoughtful digital experiences.

## Features

- **Interactive Homepage:** Custom animated character that responds to cursor movements, with a personalized introduction and resume link.
- **Projects I've Worked On:** Five featured projects spanning AI/ML, computer vision, accessibility, and full-stack development, with project previews, technology badges, achievements, and GitHub links.
- **My Other Experiences:** Professional experiences, technical programs, and achievements displayed through interactive cards with hover-to-reveal certificates and image previews.
- **Things I Love Doing:** A creative Polaroid-style gallery showcasing my interests beyond coding.
- **Let's Talk:** An interactive section providing quick access to professional profiles and ways to connect.

## Tech Stack

**Frontend**
- React 19
- TypeScript
- Vite
- Tailwind CSS v4
- Lucide React

**Animation & Visuals**
- HTML5 Canvas
- Custom cursor-tracking animations
- WebP image sequences

**Development Tools**
- Python
- OpenCV
- MediaPipe

*Python, OpenCV, and MediaPipe were used for offline animation development and asset processing.*

## Getting Started

**1. Clone the repository**

```bash
git clone https://github.com/YOUR_USERNAME/manu-portfolio.git
cd manu-portfolio
```

**2. Install dependencies and run locally**

```bash
pnpm install
pnpm run dev
```

Open the local URL displayed in your terminal.

**3. Build and preview for production**

```bash
pnpm run build
pnpm run preview
```
